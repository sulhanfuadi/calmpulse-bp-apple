# UI Style Guide — Apple-Native Minimal

## Rules
- No decorative UI
- No verbose copy
- No-scroll per screen (watch-first)

## Color discipline
- Monochrome default (black/gray/white)
- Red only for alert/trigger
- Green only for calm/success

## Copy discipline
- 1 short title
- 0-1 support line
- Action labels 1 word where possible
