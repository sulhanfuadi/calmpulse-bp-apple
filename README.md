# CalmPulse BP — Apple Watch (watchOS-first scaffold)

CalmPulse BP adalah konsep aplikasi Apple Watch untuk membantu pengguna hipertensi muda melakukan intervensi mikro saat sinyal stres meningkat.

## Positioning
- Self-awareness support
- **Bukan alat diagnosis**
- **Bukan layanan darurat**

## Current phase
Scaffold + product/technical planning (belum full MVP logic produksi).

## Planned flow
Onboarding → IdleMonitoring → Triggered → BreathingActive → ReflectionPending → Summary

## Local development
- Xcode terbaru dengan dukungan watchOS
- SwiftUI
- Target awal: watchOS app first

## Run (scaffold)
1. Buka folder ini di Xcode, buat watchOS App target bernama `CalmPulseBP`.
2. Tambahkan source files dari folder `App`, `Features`, `Domain`, `Infrastructure` ke target watch app.
3. Run ke simulator Apple Watch.

## Safety statement
Aplikasi ini hanya pendamping self-awareness. Jika ada gejala serius atau menetap, segera hubungi tenaga medis profesional/layanan darurat setempat.
